# Requirements

This folder has two versions of the requirements.

| File | Version | Date | Written by | Content |
|---|---|---|---|---|
| [1-first-requirements-v1.md](1-first-requirements-v1.md) | 1.0, first requirements | 28 October 2026 | Masoma Rezaie (Product Owner) and team | The requirements agreed at the start of the project: purpose, scope, users, constraints, functional and non-functional requirements |
| [2-final-requirements-v2.md](2-final-requirements-v2.md) | 2.0, final requirements | 1 November 2026 | Team | The requirements of the finished system: what was implemented, the status of each requirement, the test cases that check it, use case descriptions, booking rules and what was not implemented |

The first version describes what the team planned. During the sprints some requirements changed. For example, the backend, the database connection and the admin login were added, and the contact form does not save messages. The final version describes the system as it was delivered.
